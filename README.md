# Heart Attack Risk Prediction

## Overview
This project is part of the Final Project for Data Mining A. It aims to analyze health-related factors and develop classification models to predict heart disease risk.

## Dataset
The dataset was obtained from Kaggle:

[Heart Attack Analysis and Prediction Dataset](https://www.kaggle.com/datasets/sonialikhan/heart-attack-analysis-and-prediction-dataset)

The dataset contains health-related variables such as age, sex, chest pain type, resting blood pressure, cholesterol, maximum heart rate, and other clinical indicators.

## Methods
The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA) and visualization
- Feature selection
- Random Forest classification
- Logistic Regression classification
- K-Means clustering
- Model evaluation using repeated holdout and cross-validation

## Results
Logistic Regression achieved the best overall performance among the evaluated models, with an average accuracy of approximately 85.79%. K-Means was used to explore patient data patterns, although its clustering quality was relatively weak.
